# 待辦桌面小工具（iPhone）

桌面上直接看到：還沒做完的緊急事（逾期、今天到期、P0；P1 不算）和各專案進度。
點小工具會打開待辦儀表板。

iPhone 小工具不能跑網頁，所以用免費的 **Scriptable** App 畫：
腳本每 15 分鐘向喵管家拿一次 `GET /widget/todos`，喵管家從「共同待辦」整理好給它。

## 一、Railway 加一把小工具專用的金鑰（只做一次）

1. Railway → 喵管家的服務 → **Variables** → **New Variable**
2. 名稱 `WIDGET_TOKEN`，值打一串夠長的亂碼（至少 32 個字，英文數字混合）
3. 存檔，等它重新部署完

> 不要用 `ADMIN_TOKEN`：這把會放在手機上，外流的話只看得到待辦，碰不到 `/admin`。

## 二、手機裝腳本

1. App Store 裝 **Scriptable**
2. 打開 Scriptable → 右上角 **＋** 新增腳本
3. 把 `todo_widget.js` 整份貼進去
4. 把第 5 行的 `貼上 Railway 的 WIDGET_TOKEN` 換成上面那串亂碼
5. 想預設看小螢的，就把第 6 行的 `"仁和"` 改成 `"小螢"`
6. 左上角把腳本名稱改成「待辦」，按 ▶ 跑一次：看到預覽就成功了

## 三、放到桌面

1. 長按桌面空白處 → 左上角 **＋**
2. 找 **Scriptable** → 選大小（中型最剛好；大型能看更多）→ 加入小工具
3. 長按剛加的小工具 → **編輯小工具**
   - Script：選「待辦」
   - When Interacting：選 **Open URL**（點了會開儀表板）
   - Parameter：想看別人的就填 `小螢` 或 `共同`；空著就用腳本裡的預設

同一個腳本可以加好幾個小工具，各填不同的 Parameter，例如一個看自己、一個看共同。

## 顯示什麼

| 大小 | 內容 |
|---|---|
| 小 | 緊急件數（大字）＋前兩件 |
| 中 | 左邊緊急前 4 件，右邊前 3 個專案的進度條 |
| 大 | 緊急前 7 件，專案前 5 個 |

- 看某個人時：他自己的事＋共同的事
- 專案排序：緊急的多的在前，再看待辦件數；做完的專案不顯示
- 🔥 數字是那個專案裡還有幾件緊急
- 連不上時會顯示上一次的資料，標「舊資料」

## 出問題時

- **「待辦小工具連不上」**：TOKEN 沒貼對，或 Railway 還沒設 `WIDGET_TOKEN`（回 503）
- **數字沒更新**：iOS 會自己決定小工具多久刷新，通常 15～30 分鐘；點進 Scriptable 跑一次可以馬上更新
