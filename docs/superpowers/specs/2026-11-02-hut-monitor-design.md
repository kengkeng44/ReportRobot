# 山屋／營地名額監控 設計

日期：2026-11-02
來源：Notion 待辦 #12「自動監控熱門露營區營位釋出…登山名額也可以做」；規則依 `~/.claude/skills/hut-apply/SKILL.md`。

## 目標

每天掃三次熱門高山山屋／營地未來 2 個月的空床，有變化就寄 Gmail；LINE 傳「山屋」可以查最新狀況。申請仍由使用者在 Claude Code 用 hut-apply 代填到驗證碼前。

## 不做（紅線）

- 不自動送出申請、不碰驗證碼、不替使用者登入、不存隊員個資。林業署須知：「以非法程式進行申請或干擾系統」→ 全隊停權 3 年（檜谷永久）。
- 不高頻查詢：一天 3 次，請求間隔 2–3 秒。
- 不做商業露營區（另立專案）。
- 不主動推 LINE（每月 200 則額度給記帳／待辦用）。

## 監控範圍

### 完整監控（林業署 PHP 子站，同一套系統，共用一支解析器）

| 地點 | 來源 | 狀態 |
|---|---|---|
| 嘉明湖山屋、向陽山屋、嘉明湖營地 | `https://jmlnt.forest.gov.tw/room/` | 已實測，不用登入：「剩餘床位 (N) 目前報名 : M」。**2026-11-10 起停掉自動查詢**：對程式 UA 回 HTTP 500（瀏覽器 UA 回 200），照「被擋不換 UA」不繞；`SITES` 裡標 `auto: False` |
| 天池山莊＋營地 | `https://tconline.forest.gov.tw/room/` | 已實測，不用登入：「天池山莊 床位 (N) 目前報名 : M」 |
| 檜谷山莊＋營地（北大武） | `https://kgonline.forest.gov.tw/room/` | 站存在；床位格式實作時確認 |

抓法（參考 exhaJim/taiwan-cabin-crawler 的做法，自己重寫，不抄碼）：GET `room/index.php` 取 `<input name="csrf">`，再 GET 同頁帶 `date_set[year]`、`date_set[month]`、`csrf` 換月份；每天一格 `<a id="tds_DD">`，格內文字用 regex 取地點／剩餘／報名。抓當月＋後 2 個月。

### 一站式（hike.taiwan.gov.tw）：Windows 上用真瀏覽器抓

| 地點 | 查詢頁 | 制度 |
|---|---|---|
| 排雲山莊 | `bed_6.aspx`（option 3） | 抽籤：只看住宿前 30 天內的遞補 |
| 九九山莊 | `bed_0.aspx` | 先到先得 |
| 七卡山莊等雪霸山屋 | `bed_1.aspx` | 先到先得 |
| 奇萊山屋、南湖山屋 | `bed_4.aspx` | 先到先得 |
| 眠月線 | 查無公開名額 | 只做開放日提醒（進入日前 60 天） |

為什麼要真瀏覽器（2026-11-02 實測）：床位數字要「選宿營地→按查詢」的 ASP.NET postback 才載入；用程式直接送 postback 回 `Request Rejected … support ID`（網站前有 WAF 擋非瀏覽器請求）。

做法：照 hiiamyes/taiwan-hiking-form-filler（MIT）`check-paiyun-capacity.js` 的抓法改寫成 Python Playwright：開頁 → 從「宿營地」下拉選單選地點 → 查詢 → 讀當月＋下月月曆，每格解析「餘額 (床,帳) 排隊預約 N 審核中 N 核准入園 N」。檔頭保留 MIT 聲明與出處。

- 位置：`tools/hut_browser.py`＋`tools/hut_browser_local.ps1`（照 `tools/line_scan_local.ps1` 的本機排程寫法），Windows 工作排程器 07:00／16:30／23:30。
- headless、不搶滑鼠；地點依序查，間隔 3–5 秒；一次約 6 個地點。
- 結果 POST 到 Railway `/admin/hut-ingest`（沿用 `X-Admin-Token`＝ADMIN_TOKEN；本機讀 `~/.hut_monitor/admin_token`，照 tools/line_scan.py 的做法）。本機比伺服器早 10 分鐘跑（06:50／16:20／23:20），60 分鐘內的資料才算數。Railway 把它併進同一份快照、同一封信。
- 紅線：不裝 stealth 外掛、不偽造瀏覽器指紋、不換 IP。真瀏覽器也被擋（出現 Request Rejected）→ 該次停止、信裡標示，連續 3 次就通知，不硬闖。
- 電腦沒開：Railway 該次沒收到一站式資料 → 信裡標「一站式本次沒查到（電腦沒開）」，快照保留舊值。

一站式各地點同時也列在「未來 7 天抽籤日／開放日」區塊。

抽籤制（排雲、嘉明湖／向陽、檜谷）在抽籤前的「剩餘」只是還沒分配，不算釋出；這類只監控抽籤後（住宿前 30 天內）的遞補／空床名額，抽籤前的日期只出現在「未來 7 天抽籤日」區塊。天池 5～29 天的空床抽籤同理。

## 架構（放進 ReportRobot，Railway 上跑）

照 ReportRobot 一個功能一檔的平鋪結構：

- `hut_sources.py`：林業署三站共用 `fetch_forest(site) -> list[Slot]`。`Slot = (site, hut, date, remaining, applicants)`；數字缺漏存 `None` 不存 0（照 hiiamyes 的資料約定）。HTTP 用 `http_utils` 既有工具（實作時確認介面，沒有合用的就在本檔內建 session），固定瀏覽器 UA、請求間隔 2–3 秒。
- `hut_monitor.py`：`run_check()`：抓全部 → 跟上次快照比對 → 產生變化清單 → 有變化就寄信。快照存在 module 層 dict（記憶體）；server 啟動時先跑一次當基準、不寄信。部署後最多漏掉一次變化，可接受。
- `hut_calendar.py`：依 hut-apply 規則算未來 7 天的抽籤日、開放日、繳費截止。玉山抽籤日查 `bed_8.aspx`，不自己推。用既有依賴 `holidays.Taiwan` 判斷「隔天放假」的晚上（週五、週六、連假前一晚）。
- `hut_info.py`：每個地點的交通卡（固定資料，見下）。
- `hut_report.py`：組 email（HTML）和 LINE 回覆文字。
- `server.py`：加三個 CronTrigger 排程：07:00、16:30、23:30（Asia/Taipei）。
- `command_router.py`：關鍵字「山屋」→ 回最新快照摘要（reply，不扣 push 額度）。

### 為什麼是這三個時間

- 07:00：先到先得系統當天開放、前一晚 23:00 雪霸排床位結果出來後。
- 16:30：嘉明湖／天池／玉山 15:00 抽籤、16:00 公布之後。
- 23:30：當天取消、繳費期限過期釋出的名額。

## 通知內容（Gmail，用現成 `mailer.send_email`）

有變化才寄，一天最多 3 封。標題例：「山屋：嘉明湖 12/6(六) 新釋出 4 床」。

信件順序：
1. **重點**：週末或連假、空位 ≥ 2 的「新出現」或「變多」。
2. 完整變化表：地點／日期／剩餘（前次→本次）／報名人數。
3. 未來 7 天的抽籤日、開放日、繳費截止。
4. 有出現在重點裡的地點附交通卡。
5. 每個重點一行可直接複製的句子：`用 hut-apply 申請 嘉明湖 2026-12-06 2人`。

使用者需在 Gmail 建篩選器：寄件者為 ReportRobot、主旨含「山屋：」→ 加標籤、標為重要、不要略過收件匣。

## LINE「山屋」回覆

最新一次檢查時間＋各地點未來 2 個月內空位 ≥ 2 的週末／連假日期（每地點最多 5 個）＋「完整內容看 Gmail」。

## 錯誤處理

- 單一網站請求失敗：重試一次；仍失敗 → 該站本次跳過，信裡標「X 站本次沒查到」，**不當成全滿**，快照保留舊值。
- 解析出 0 筆：當成網站改版／解析壞掉，同上處理。
- 同一站連續 3 次失敗 → `admin_notify.notify_admin`。
- Railway 國外 IP 被擋：實作第一步在 Railway 上用 `/admin` 類端點對每個來源做一次 GET；被擋就改方案 B（Windows 工作排程器跑同一支 `hut_monitor.run_check()`，結果 POST 回 Railway 給 LINE 查詢用）。

## 測試

- 每個來源存一份 HTML 樣本到 `tests/fixtures/hut/`，解析器單元測試。
- 比對邏輯：新出現、變多、變少（不通知）、站點失敗不覆蓋快照。
- `hut_calendar`：日期算法（前 2 個月、前 60 日、2/29 邊界、連假判斷）。
- `hut_report`：重點排序、空位門檻 2。
- 跑全套 pytest 不退步。

## 實作順序

1. Railway 連線實測三個林業署站（決定 A 或 B）。
2. 林業署共用解析器＋比對＋寄信，先上線。
3. 本機實測 Playwright 開一站式查排雲，確認不被 WAF 擋、存 HTML 樣本。
4. `tools/hut_browser.py`＋`/hut/ingest`＋Windows 排程。
5. `hut_calendar`、LINE「山屋」指令。
6. 交通卡逐一官方確認。
